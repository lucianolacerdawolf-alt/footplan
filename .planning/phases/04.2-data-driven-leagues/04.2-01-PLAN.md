# Phase 4.2 Plan: Data-Driven Leagues

## Goal

Replace hardcoded Premier League with a data-driven multi-league system.
User selects a league (PL, La Liga, Bundesliga, Serie A), then picks a team.
Save isolation per league. CPU behavior varies by league profile.
European slots and relegation zones rendered visually in the standings table.
