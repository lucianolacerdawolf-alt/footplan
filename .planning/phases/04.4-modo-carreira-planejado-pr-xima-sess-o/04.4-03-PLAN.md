<objective>
Close the exact TypeScript-silent gap RESEARCH.md's Pitfall 2 flags: five files each independently redeclare a local `Screen`/`MatchContext` type instead of importing a shared one, and TypeScript's contravariant parameter checking lets a wider-domain setter satisfy a narrower-domain expected type without a compile error — meaning a career screen navigation could "work" from App.tsx's perspective while silently breaking `goHome`/resume-prompt/edit-tactics callbacks owned by a hook whose local union was never updated. This plan is purely mechanical: add the five new career screen values to every local `Screen` union, and add an explicit `isCareerMode` boolean to `useAppShell` (rather than overloading `matchContext`, per RESEARCH's Anti-Pattern 3 — a 'league'/'bracket' matchContext alone cannot tell a shared handler whether it owns Campeonatos or career state).

Purpose: Make the five new career screens (`career-hub`, `career-league`, `career-bracket`, `trade-propose`, `season-end`) and the career/Campeonatos distinction type-safe everywhere before App.tsx wiring (04.4-07) depends on it.
Output: All five hook files' local `Screen` unions gain the same five new literals; useAppShell gains `isCareerMode`/`setIsCareerMode` and a career-aware `handleContinueTournament`.
</objective>
